# Проверка Garage: транспорт и фотографии

## Перед началом

1. В `apps/api/.env` задайте PostgreSQL для `garage_db`, `LOCAL_DEV_WRITE=true` и `UPLOADS_DIR=./data/uploads`.
2. В `apps/mobile/.env` оставьте `EXPO_PUBLIC_API_URL=http://10.0.0.100:3000/api`.
3. После отдельного разрешения примените новую миграцию: `npx prisma migrate deploy --schema prisma/schema.prisma` из `apps/api`.
4. Перезапустите API: `npm run api` из корня. Для Expo после изменения `.env` выполните `npm run mobile -- --clear`.

## Android / Expo Go

1. Откройте «Гараж», нажмите `＋`, заполните обязательные поля.
2. Нажмите «Из галереи», разрешите доступ, выберите фото и сохраните транспорт.
3. Убедитесь, что фото видно в списке и деталях. Полностью закройте Expo Go, откройте снова и обновите — фото должно загрузиться с `http://10.0.0.100:3000`.
4. В редактировании выберите «Заменить», затем «Удалить». После каждого действия убедитесь, что результат сохраняется после перезапуска.
5. Добавьте показание пробега на деталях и после обновления списка проверьте его значение.
6. Повторите с «Камера» и проверьте отказ в разрешении: приложение должно показать понятное сообщение без красного экрана.

## iPhone / Expo Go или development build

1. Убедитесь, что iPhone находится в той же сети и URL API использует доступный LAN-адрес компьютера.
2. Повторите Android-сценарий: библиотека, камера, замена, удаление, перезапуск и пробег.
3. На iOS подтвердите системные тексты доступа к Photos и Camera; при выборе HEIC приложение преобразует изображение в JPEG до upload.
4. Если текущая версия Expo Go не содержит совместимые нативные модули проекта, соберите development build с той же конфигурацией Expo.

## Автоматические проверки

```bash
npm run typecheck --workspace=@garage/mobile
npm run typecheck --workspace=@garage/api
npm run test --workspace=@garage/api
npx prisma validate --schema apps/api/prisma/schema.prisma
```

Автоматические тесты проверяют сохранение JPEG с безопасным именем, отклонение не-изображения и ответ 404 для отсутствующего транспорта. Камера, системные разрешения, iOS HEIC и реальная загрузка на телефон требуют ручной проверки.
